# Completed native traces: read-only comparison protocol

8 September 2026. Written before running the comparison, after the three
planned six-step native diagnostics completed. No new native run is proposed.
The previous force-trace design and all completed stages remain immutable.

Pin the native report at SHA256
`94ed097aa774b930c065bb1710d2c4f4f9d4cf618adcf09c52b23debf8822b97`
and its six rank-file hashes. Reuse its completed structural/arithmetic and
independent native-state checks; do not rerun native validation or yt readers.

Compare every off-A/off-B, off-A/on and off-B/on combination at all 13 native
phases, the seven prospectively selected IDs and all six force/energy-rate
fields. Expect 546 owner accumulators per case and 1,638 paired comparisons.
Align exact phase/time-bit/ID/component keys, not native rank or rounded time.
Missing or unmatched groups stop the analysis; no interpolation or dropping.

Retain the owner's original baseline and actual native energy initialization.
For post-initialization force sums, use the value after a recorded reset, if
present. A repeated reset or one after force updates is an unexpected failure.
Do not erase the fact that pre-initialization values may already differ.

Replay the actual ordered arithmetic to each saved endpoint. Classify
different starting values separately. Then compare strict multisets of event
kind, operation, exact operand, partner ID, factor count/bits and activity.
A remote event is the actual incoming subtotal, not a fully resolved remote
neighbor list or sender MPI rank. Only identical starts and strict contribution
multisets with different reproduced endpoints support an order explanation
for that selected accumulator in these instrumented cases.

Keep all classification counts and every paired summary, including identical
endpoints with changed inputs. Report endpoint differences separately from
input classifications, first chronological difference, and the first three
differing examples per category in deterministic time/phase/ID/field order.
Do not select only passing order examples. Publish bit patterns as hex strings
and retain native rank/sequence/byte-offset references for reproducibility.
Report maxima separately by component because acceleration and energy-rate
units differ. No physical tolerance or significance percentage is introduced.

Synthetic tests cover identity joins, cache exclusion, real initializer resets,
missing/duplicate groups, signed zero, strict provenance and order attribution.
Review selected examples independently before publication. Frozen source,
input pins, report and failed attempts are retained under a new analysis path.

Even a positive order result is not proof about untouched original trajectories,
the later velocity kick, every remote constituent or observer effects. The
existing one-spacing density gate remains failed. No full Gasoline control is
enabled. Further scientific acceptance requires an explicit decision; do not
respond by indefinite additional traces or post-hoc threshold relaxation.
