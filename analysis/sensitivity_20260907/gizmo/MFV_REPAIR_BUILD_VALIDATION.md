## What the tests establish

The C test harness extracts the actual repaired input-dispatch and integrated
mass-update fragments. Nine tests cover zero/positive/negative flux, both
local and imported input paths, unequal steps, the equal-step double-visit
schedule, the active-neighbor branch, donor-mass limiting and zero timestep.
Each tested exchange adds and subtracts opposite mass increments. The active
branch is synthetic coverage, not a claim that this optimization is enabled.

These tests omit the native neighbor search, Riemann solver, MPI transport,
kicks and thermal evolution. They do not certify an evolved run or global
conservation over a trajectory. The test output and generated harness remain
local; no simulated frame was generated by these tests.

A separate read-only DWARF review confirms that the original and both new
executables report identical compiler/options and selected global, particle
and gas record layouts. Record sizes are 15864, 288 and 384 bytes. The native
fast-math constructor remains present. This is not a full restart-executability
test or a new dynamic FTZ measurement.

In the exact preprocessed existing MFM configuration, the uninitialized local
feeds only a subsequently unused maximum. The optional half-step/upwind and
MFV integrated-mass branches are absent. This is a limited source finding,
not certification of every MFM configuration or permission to rerun accepted MFM.
