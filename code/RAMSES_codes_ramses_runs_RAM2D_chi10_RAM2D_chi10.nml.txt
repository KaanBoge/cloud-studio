! RAMSES cloud-wind matched setup (multi-code comparison), 2D, chi=10
!
! GEOMETRY NOTE: current RAMSES supports a single interior coarse cell, so the
! domain is a SQUARE box [0,20]^2. Mapping to the physical SPEC frame:
!   x_phys = x_box - 3   (x_phys in [-3,17], as in the SPEC)
!   y_phys = y_box - 10  (y_phys in [-10,10]; SPEC asks [-5,5] - RAMSES box is
!                         2x wider in y; outflow boundaries are simply farther
!                         from the cloud, cloud dynamics unaffected)
! Cloud center at box (3,10) = physical origin, radius 1.0.
! Uniform effective resolution levelmin=levelmax=9: dx = 20/512 = 0.0390625,
! IDENTICAL to the SPEC 512x256 grid spacing on [-3,17]x[-5,5].
! For light AMR instead, set levelmin=8 (or 7) and keep levelmax=9;
! &REFINE_PARAMS err_grad_d/err_grad_p then track cloud, bow shock and wake.
!
! t_cc = sqrt(10)*1.0/2.582 = 1.2249 ; t_end = 5*t_cc = 6.12
! Outputs every 0.153 (40 dumps), matching the Athena ATHW2D_chi10_512 run.
! Run:  nice -n 19 mpirun -np 2 ../../bin/ramses_cw2d RAM2D_chi10.nml
