# Cloud Studio runs

Pictures, films and 3D surfaces of the runs shown on [Cloud Studio](https://kaanboge.github.io/cloud-studio/), one folder per run, with every saved state of each run. The runs go from t = 0 to 5 t_cc, except where an entry says that a run stops earlier. The site reads these files from a fixed commit of this branch.

Each folder holds `edge.png` and `face.png` (one 128 pixel row per saved state, column density on a logarithmic scale from 0.008 to 5 in units of the initial cloud density times the cloud radius), two posters, two films at 60 fps (`film-edge.mp4`, `film-face.mp4`), the 3D surfaces in `3d/`, and the run's catalog entries (`entry.json`, `entry3d.json`).
