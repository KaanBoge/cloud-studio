# Cloud survival in supersonic winds

**[Read the paper (PDF)](Cloud_survival_OJA.pdf)** · **[Download the Overleaf project](Cloud_survival_OJA_Overleaf.zip)**

The 14-page manuscript uses the Open Journal of Astrophysics LaTeX class. This revision expands the introduction's literature context and the MFV/Arepo discussion, including particle-spacing and numerical-support hypotheses and the measured Arepo resolution dependence. Previously integrated results and figures are retained. Untested explanations and unfinished controlled experiments remain explicit.

For Overleaf, upload the ZIP, choose `main.tex` as the main document, and select XeLaTeX. The package includes the class, bibliography, figures and saved scalar reductions. The compiled PDF is included for comparison.

The source components and numerical results retain the attribution and license scope recorded in [the source package](../code/paper_20261026/) and [repository licensing](../LICENSING.md). This folder contains reduced data and presentation artifacts, not the full native simulation outputs. Acceptance of a numerical output screen does not establish physical convergence.
