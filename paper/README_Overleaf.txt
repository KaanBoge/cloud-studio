Cloud survival in supersonic winds

Upload Cloud_survival_OJA_Overleaf.zip using New Project > Upload Project.
Set main.tex as the main document and select XeLaTeX as the compiler.
The package holds the Open Journal of Astrophysics class, the bibliography,
the figures, the saved dense mass histories and the plotting scripts.
The compiled manuscript is Cloud_survival_OJA.pdf (15 pages).

This revision brings all twelve methods to the finest resolution, n = 128,
shows all twelve at that resolution in Figure 1, adds Table 2 with the dense
fractions of every calculation, and adds the boundary control: Athena++
repeated in the two periodic domains used by the moving mesh and particle
based methods (Section 3.3, Figure 4).
