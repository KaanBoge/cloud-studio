# What the site holds

Cloud Studio presents my ongoing cloud crushing research: a dense cloud in a supersonic wind, simulated with twelve hydrodynamic methods. This page lists what the public repository and the site hold now.

| Part | Contents |
|---|---|
| Library | Every run as a card with its code, contrast and level, with films and pictures |
| 3D viewer | Two density surfaces of every saved state, with playback, side by side comparison and capture |
| Compare page | Edge on and face on column density pictures on one colour scale |
| Research page | The setup, how to read the library, the main results, the data and the downloads |
| Paper | [Cloud survival in supersonic winds](../paper/Cloud_survival_OJA.pdf), with its LaTeX source and reduced data in [paper/](../paper/) |
| Archive | Earlier runs, films, image sets, terrain views and the first 3D volumes |
| Earlier logs | The progress log and the verification log of September 2026 |
| Analysis | Scripts, reports and figures in [analysis/](../analysis/), listed with checksums in [research-files.csv](../data/research-files.csv) |

The comparison of the paper uses χ 100, a Mach 2 wind and levels 3, 4 and 5, with 101 saved states per run up to 5 t<sub>cc</sub>. The September 2026 [velocity setup study](../analysis/sensitivity_20260907/resolution_summary_v2/README.md) measured how the starting velocity at the cloud edge changes the dense gas history within each code.

The [data guide](DATA.md) describes the downloads and the files behind the pages. The [methods guide](METHODS.md) describes the steps from a simulation to the site. The website and viewer software are MIT licensed within the [documented scope](../LICENSING.md); the simulation codes keep their own terms.
