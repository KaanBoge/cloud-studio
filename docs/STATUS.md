# Currently published contents

Cloud Studio is an **ongoing project by Kaan Boge**. This page describes what
the public repository contains, not a final paper or a simulation schedule.
Counts refer to the dated 9 September 2026 catalog.

| Collection | Published contents |
|---|---|
| Velocity-sensitivity analysis | 50 accepted controls, 25 pairs, 5,054 analyzed native states |
| Historical 3D viewer | 174 mapped entries and 11,913 indexed frames |
| Analysis catalog | 919 scripts, reports, diagnostic records, figures and provenance files |
| Enzo level-5 checks | Diagnostic pair and independent sharp-run checks, outside the accepted paired-analysis total |
| Other evidence | Tracking/cooling audits, performance measurements and lossless-compression tests |
| Browser software | Interactive 3D viewer, movies/images studio and searchable research hub |

The [all-code report](../analysis/sensitivity_20260907/resolution_summary_v2/README.md)
contains the accepted within-code comparisons. The [frame inventory](../data/streaming-inventory.csv)
describes the separate historical visualization collection. The counts are not
interchangeable: historical entries are not automatically accepted controls,
and published meshes do not contain every native fluid field.

The current reports document code-specific limitations, including Gasoline's
failed repeatability gate, cooling-labelled historical cases with cooling
disabled, and tracking tests that do not demonstrate complete material retention.
These limitations remain visible alongside the results.

The [data guide](DATA.md) describes the downloads and local/native distinction.
The [methods guide](METHODS.md) explains the simulation-to-visualization process.

[documented scope](../LICENSING.md); upstream software keeps its own terms.
